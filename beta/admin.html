이 기기에서 처음 한 번만 설정해요

사진을 올리려면 GitHub 토큰이 필요해요. 토큰은 이 브라우저에만 저장되고, 사이트나 저장소에는 올라가지 않아요. 기기(노트북·아이패드·휴대폰)마다 한 번씩 입력해요.

  1. GitHub의 새 토큰 만들기(Fine-grained)를 열어요.
  2. Repository access에서 Only select repositories를 고르고 seoul-photo-map과 seoul-photo-map-notes 두 개만 선택해요.
  3. Permissions → Repository permissions → Contents를 Read and write로 바꿔요. 다른 권한은 그대로 둬요.
  4. 만료일을 정하고(예: 1년) 만든 뒤, 나온 토큰(github_pat_…)을 아래에 붙여 넣어요.
